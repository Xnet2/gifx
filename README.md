# GifX – ממיר וידאו ל-GIF

הופך סרטון ל-GIF באיכות גבוהה, ישר בדפדפן. הסרטון לא עולה לשום מקום, ואחרי שהדף נטען לא צריך אינטרנט.

**להמרה באתר:** https://xnet2.github.io/gifx/

**לשימוש בלי אינטרנט:** מורידים את הקוד (Code ← Download ZIP), פותחים את התיקייה ולוחצים פעמיים על `index.html`.

## איך משתמשים

1. בוחרים סרטון (או גוררים אותו לחלון)
2. גוררים את הידיות על ציר הזמן כדי לבחור את הקטע. אפשר גם לחתוך את התמונה
3. בוחרים גודל, תנועה ואיכות, ולוחצים "יוצרים GIF"

בהגדרות הנוספות יש מהירות, הלוך ושוב, מספר חזרות, מספר צבעים, כיווץ ועוד.

## למה זה יוצא איכותי

- לכל תמונה בסרטון נבנית פלטה של עד 256 צבעים משלה, לפי איך שהעין רואה צבעים
- מעברי צבע מוחלקים, כך שאין "פסים" בשמיים ובפנים
- התמונה מוקטנת בכמה שלבים, כך שאין ריצוד ומדרגות
- רק מה שזז נשמר מפריים לפריים, אז הקובץ קטן יותר בלי לפגוע באיכות
- ההמרה רצה על כל ליבות המעבד במקביל

הכל כתוב ב-JavaScript בלי ספריות חיצוניות. עובד בכרום, אדג' ופיירפוקס, במחשב ובטלפון.
